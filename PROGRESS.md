## 2. Как работать с проектом

- **Node 22.** В репозитории `frontend/.nvmrc` = 22 и `engines >=22.12`. Системная Node 20.18 не подходит (vitest 5 требует 22+). Я ставил `PATH="$HOME/.nvm/versions/node/v22.15.1/bin:$PATH"`.
- Команды из `frontend/`: `npm run typecheck -w @podbor/admin`, `npm test -w @podbor/admin`, `npm run build -w @podbor/admin`.
- Запуск вручную (делаете вы): `npm run dev:mocks -w @podbor/admin` — без бэкенда, на MSW. `npm run dev:admin` — с прокси на `localhost:8080`.
- Учётки для моков — в `apps/admin/src/mocks/fixtures/ids.ts` (`MOCK_ACCOUNTS`, код TOTP `MOCK_TOTP_CODE`). Одна учётка с настроенной 2FA, вторая — для сценария первого входа.
- Управление моками из консоли браузера (только в режиме моков): `__mocks.control.failOnce('POST /admin/reports/:id/approve', { kind: 'app', status: 409, errorCode: 'REPORT_NOT_PENDING_REVIEW' })`, `__mocks.config.expiresIn = 300`, `__mocks.reset()`.
- **Правило «ничего не запускать»** записано в `PLAN_FRONTEND*.md` и `agent-tasks/{admin,design,miniapp}/README.md`, а также в памяти ассистента. В самих файлах `ADM-*.md` и `DS-*.md` критерии «запускается на localhost» остались как были (перекрыты README).

## 4. Отступления от текста задач (с причинами)

1. **React 19, Vite 6, `react-router-dom` 6, `"*"` вместо `workspace:*`.** В `packages/ui` peer-зависимость `react ^19`, и `apps/web` на тех же версиях; npm не понимает `workspace:*`. React 18 из задачи не взят: в монорепо было бы два React.
2. **Data router** (`createBrowserRouter`) вместо `<BrowserRouter>`: `useBlocker` работает только с ним. Роуты вынесены в `routes.tsx`.
3. **Плагин `tailwindcss()`** добавлен в `vite.config.ts` — без него `@import "tailwindcss"` не работает; в сниппете задачи его нет.
4. **`pool: 'threads'`** в vitest: форки не завершаются в песочнице (`kill EPERM`).
5. **Тесты на happy-dom** + заглушка `getComputedStyle` в `test/setup.ts` (иначе падает `vaul`).
6. **Поле `filteredRows`** в `useClientTable` — нужно для итога выплат по всем найденным строкам, а не по странице.

## 5. Решения, которые я принял сам (нужно ваше подтверждение)

- Автовыход происходит **за 60 секунд до** реального конца токена, а не в момент конца (чтобы действие в последние секунды не упало 401).
- Поиск подборщиков находит телефон **и в том виде, в каком он показан на экране, и в том, в каком хранится** (`+375 29 100-01-05` и `375291000105`).
- **Первый клик по колонке, по которой уже отсортировано по умолчанию, переворачивает направление** (иначе клик «не срабатывал» визуально).
- Текст удаления опубликованного отчёта: **«ссылка у купивших перестанет работать»** — это текущее поведение бэкенда; флаг `features.deletionKeepsAccess` переключит текст на целевой («купившие сохранят доступ»), когда будет сделан B-05.
- Видео-плейсхолдер отдаётся как **картинка**: `<video>` не умеет показывать SVG. Надпись на нём: «Видео … не обработано».
- В очереди «Подборщик» показан сокращённым `id` (8 символов), полный — в подсказке (имя придёт с ADM-12).
- Предупреждение «подборщик не верифицирован» в карточке работает **только если** списки подборщиков уже загружены в кеш (запрос ради него не делается).
- Мобильный порог — `max-width: 767.98px` (`hooks/useMediaQuery.ts`).
- Мок `GET /admin` без слэша отдаёт 404 формы B, как настоящий Spring.

## 6. Что не проверено

- **Всё визуальное:** вёрстка десктопа и телефона, шторка меню, диалоги, баннеры, таблицы. Тесты проверяют DOM и поведение, а не внешний вид.
- **Работа с настоящим бэкенд:** прокси `/api` проверялся только на заглушке (ответ 405); реальный Spring не запускался. Мои типы сверены с Java-DTO чтением кода, но не прогоном.
- **Стили `packages/ui` в сборке:** проверено только тем, что нужные классы попали в CSS.
- **Скриншоты:** Chrome и Firefox в песочнице падают (exit 134), поэтому их нет.
- **Предупреждение React** про `key` в списке `Cell` (мобильная очередь) наблюдалось в одном прогоне, в последнем — нет. Причина не выяснена.

  - PID 90759 — мой dev-сервер, порт 5199;

  - PID 26222 — порт 4173 (vite preview), **не мой**, возможно ваш.
  Команда: `kill 51017 90759 51466` (26222 — по вашему усмотрению).
- **`apps/web` не собирается** (импортирует MUI, которого нет): известно заранее, это WEB-1. Из-за этого корневые `npm run typecheck` и `npm run build` падают на `web`; для админки — `-w @podbor/admin`.

- **Мои правки несколько раз портили JSX** (мусор в атрибутах, потерянные скобки). Все такие места нашлись типизацией и исправлены, но перед переносом файлы стоит пробежать глазами.
- Типы DTO написаны **вручную** и могут разойтись с бэкендом; после springdoc (BE-12b) нужна ADM-17.
- `MOCK_TOKEN`, id админа и учётки в моках — жёстко заданные значения; в прод-код моки не попадают (подключаются динамически только при `VITE_API_MOCKS=1`).
