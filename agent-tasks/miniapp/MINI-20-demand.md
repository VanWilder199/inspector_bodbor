# MINI-20: Спрос

## Цель
Подборщик видит, какие машины ждут покупатели, и может сразу создать отчёт.

## Контекст
- **Источник:** `PLAN_FRONTEND_MINIAPP.md`, раздел 1.1 (сценарий J), раздел 5 BE-15, фича MINI-20
- **Бэкенд:** ❌ **БЛОКЕР** — эндпоинта `GET /inspector/demand` нет вообще

## Зависимости
- MINI-07, **BE-15** (блокер)

## ⚠️ Блокер
Нет эндпоинта. Предлагаемый контракт (раздел 5, BE-15 — предложение): `GET /inspector/demand?limit=50` по `report_requests`, сгруппировано по `car_id`, сортировка по `waitingCount desc`:
```json
[
  {
    "car": { "id": "0e7d…", "make": "Volkswagen", "model": "Passat", "year": 2017, "vin": null, "avbyListingUrl": "…", "listingStatus": "active" },
    "waitingCount": 7,
    "lastRequestedAt": "…",
    "publishedReportsCount": 0,
    "myReportId": null
  }
]
```
По умолчанию исключать машины с опубликованным отчётом. `myReportId` — черновик этого подборщика по машине, если есть (тогда кнопка «Продолжить», не «Создать»). **Контракт не согласован с бэкендом, делать на моках с явной пометкой.**

## Требования (на момент появления BE-15)
`/demand`: список машин (марка, модель, год, «N ждут», дата последнего запроса), кнопка «Открыть на av.by» (`openLink`), «Создать отчёт» (переход в MINI-07 с подставленной ссылкой из `avbyListingUrl`) или «Продолжить черновик», если есть `myReportId`.

## Acceptance Criteria
- [ ] список отсортирован по числу ожидающих
- [ ] «Создать отчёт» открывает MINI-07 с ссылкой из `avbyListingUrl`
- [ ] при `myReportId` открывается существующий черновик
- [ ] пустое состояние «Пока запросов нет»
- [ ] пока BE-15 не реализован: экран показывает заглушку «скоро» (как в MINI-06), не пытается ходить на несуществующий эндпоинт в проде

## Gotchas
1. **Эндпоинта нет вообще** — так же, как MINI-19, это отсутствие контракта, не ограничение существующего.
2. Переход «Создать отчёт» должен передавать `avbyListingUrl` в MINI-07 тем же механизмом `?url=`, что и из бота (BOT-02) — не изобретать отдельный способ передачи ссылки.

## Промпт для агента
```
Реализуй экран «Спрос» согласно MINI-20-demand.md.

ВАЖНО: эндпоинт GET /inspector/demand (BE-15) ПОКА НЕ СУЩЕСТВУЕТ на бэкенде. Работай на MSW-моках по предполагаемому контракту из раздела 5 BE-15 плана PLAN_FRONTEND_MINIAPP.md, явно помечая контракт как предположение:
1. /demand: список машин (марка/модель/год/«N ждут»/дата), сортировка по waitingCount desc
2. Кнопка «Открыть на av.by» через openLink() из Telegram SDK
3. Кнопка «Создать отчёт» → переход в /reports/new?url=<avbyListingUrl> (тот же механизм ?url=, что в MINI-07/BOT-02)
4. Если myReportId присутствует — кнопка «Продолжить черновик» вместо «Создать»
5. Пустое состояние «Пока запросов нет»
6. Замени текущую заглушку «скоро» из MINI-06 на реальный экран, но только при включённых моках — в продакшне без реализованного BE-15 оставь заглушку

Проверь acceptance criteria на моках.
```
